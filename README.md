## Development

Extract this ZIP and open a terminal in the extracted folder. Install [Bun](https://bun.sh), then run:

```sh
bun install
bun run dev
```

Open the local address printed in the terminal. The logo is included as a real image; no Lovable asset connection is needed.

```sh
bun run test
bun run build
```

## Your project pictures

The three "Results that speak" cards show a gradient cover until you add real
screenshots. Drop images into `src/assets/projects/` named after each project:

```
agropulse-ai.jpg
medcore-hms.jpg
devforge-studio.jpg
```

JPG, PNG, WEBP and AVIF all work. Each picture appears on its card and at the
top of that project's pop-up — no code changes needed.

## Before you go live

The contact details in `src/lib/estimator.ts` (`CONTACT`) are placeholders: the
WhatsApp number, email address and social links. Replace them with your real
ones. The project samples, customer quotes and stats are also stand-in content.
Estimator week ranges are illustrative estimates, not confirmed delivery commitments.
