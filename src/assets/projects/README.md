# Project pictures

Put your real project screenshots in this folder. Each file name must match a
project slug:

| Project          | File name to use       |
| ---------------- | ---------------------- |
| AgroPulse AI     | `agropulse-ai.jpg`     |
| MedCore HMS      | `medcore-hms.jpg`      |
| DevForge Studio  | `devforge-studio.jpg`  |

Accepted formats: JPG, JPEG, PNG, WEBP, AVIF. Best result: landscape, roughly
1200x800 or wider, same aspect for all three.

Add a file and the matching card cover (plus the top of its pop-up) switches to
your picture automatically. Remove it and the gradient cover comes back.
